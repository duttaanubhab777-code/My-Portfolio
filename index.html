I'm a full-stack developer who loves turning ideas into real, working products — from the interface to the server. I build UIs with HTML, CSS, JavaScript & React and power them with Node.js, Express & MongoDB.

My biggest solo build is Email Sender — my own contact-form API, like Formspree or Web3Forms, with OTP accounts, API keys, an admin panel, a retry queue so no message is ever lost, and an installable PWA. It now powers the contact form on this very portfolio, and I built all of it from my phone.

I also team up with my friend Arnab Adhikari (@arnabadhikari777), who's great with Flask and databases. I enjoy learning by building — from AI chat apps to calculators, QR tools and result analyzers.
